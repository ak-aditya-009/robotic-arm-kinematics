# CAD files

Drop the structural design files for the arms here (STEP / STL / native
SolidWorks or Fusion files).

Suggested names:

- `arm_3dof_assembly.step`
- `arm_4dof_assembly.step`

Link lengths in the CAD model should match the values in `src/config.py`,
otherwise the kinematics will not line up with the physical arm.
